# API 응답 보고 규칙

## 1. JSON 구조 준수
API 조회 결과를 사용자에게 보고할 때는 반드시 해당 API가 반환한 **JSON 객체의 키(Key) 순서**를 엄격히 준수해야 합니다.

- 임의로 중요도에 따라 순서를 바꾸지 마십시오.
- 계층 구조(Nested Objects)를 그대로 유지하여 설명하십시오.
- 누락되는 데이터 없이 전체 구조를 조망할 수 있도록 보고하십시오.

## 2. 보고 형식
1. **계층별 헤더 사용**: JSON의 대분류(예: `originProduct`, `smartstoreChannelProduct`)를 명확히 구분합니다.
2. **필드명 병기**: 한글 설명과 함께 실제 JSON 키 값을 괄호 안에 병기합니다.
3. **데이터 타입 보존**: 리스트, 불리언, 숫자 등의 타입을 명확히 표현합니다.
