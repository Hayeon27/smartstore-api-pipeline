# 📦 상품 등록 및 상태 관리 가이드

API v2를 활용하여 상품을 등록하고, 전시/판매 상태를 정밀하게 제어하는 방법을 안내합니다.

## 1. 일반 상품 등록
최소 필수 사양(카테고리, 배송비, 고시 정보 등)을 자동으로 포함하여 상품을 등록합니다.
- **실행**: `uv run python register_product_sample.py`
- **핵심**: 사용자의 주소록 정보를 조회하여 출고지/반품지 ID를 자동으로 매핑합니다.

## 2. 전시 및 판매 중지 상태 등록
판매하지 않고 목록에만 관리하거나 특정 목적으로 중지된 상품을 등록할 때 사용합니다.
- **실행**: `uv run python register_suspended_product.py`
- **참고**: 신규 등록 시 서버가 상태값을 무시할 경우를 대비하여 **2단계 업데이트(Update)** 프로세스가 포함되어 있습니다.

## 3. 상태 업데이트 및 디버깅
- **[update_status_v2.py](../update_status_v2.py)**: 등록 후 상태를 강제로 수정하는 예제입니다.
- **[check_status.py](../check_status.py)**: 특정 상품의 원상품(Origin) 상태와 채널(Channel) 전시 상태를 대조하여 분석합니다.

## 💡 상품 정보 고시 (Notice)
네이버 API v2는 상품 유형별로 매우 상세한 고시 정보를 요구합니다. 본 예제는 `FASHION_ITEMS(양말)`을 기준으로 하였으며, 타 유형으로 변경 시 `detailAttribute` 내의 해당 객체를 스펙에 맞춰 수정해야 합니다.
