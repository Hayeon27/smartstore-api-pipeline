# 스마트스토어 API 파이프라인 활용 가이드

본 프로젝트를 통해 구축된 시스템을 실제 판매 운영에 활용하는 상세 가이드입니다.

---

## 1. 시스템 실행 및 명령 가이드

시스템은 크게 **수집 엔진**, **자동화 스케줄러**, **분석 대시보드** 세 가지 모듈로 구성됩니다.

### 📊 분석 대시보드 실행 (가장 추천)
현재 상점의 매출, 유입, 재고, 주문 현황을 한눈에 확인합니다.
```bash
uv run python pipeline/dashboard.py
```
- 실행 후 브라우저에서 `http://localhost:8000` 접속

### 🔄 즉시 데이터 수집 및 동기화
새로운 주문이나 통계 데이터를 즉시 가져오고 싶을 때 실행합니다.
```bash
uv run python pipeline/runner.py
```

### ⏰ 자동화 스케줄러 가동
24시간 백그라운드에서 주기적으로 데이터를 수집하고 알림을 보냅니다.
```bash
uv run python pipeline/scheduler.py
```

## 2. 권장 운영 주기 (Daily Routine)

| 시간대 | 활동 내용 | 활용 모듈 |
| :--- | :--- | :--- |
| **오전 09:00** | 지난밤 발생한 **신규 주문 및 문의** 확인 및 대시보드 매출 점검 | 대시보드 / 알림(Slack) |
| **오후 14:00** | **재고 부족 위젯**을 통해 발주가 필요한 품목 선별 및 물류 연동 확인 | 대시보드 (Logistics) |
| **수시** | 경쟁사나 트렌드 분석 후 **신규 상품 모사 등록** 테스트 | `copy_product_test.py` |
| **오후 18:00** | 오늘 하루 **유입 수 대비 전환율(결제 건수)** 분석 및 마케팅 성과 판단 | 대시보드 (Chart.js) |

## 3. 주요 기능 활용 시나리오

### ✅ 안전한 신규 상품 등록 (Safety-First)
- `register_product_sample.py`를 활용하여 새 상품을 등록할 때, 기본값이 `SUSPENSION`(판매중지)으로 설정되어 있습니다.
- 등록 후 스마트스토어 센터에서 최종 검수하고 '판매중'으로 변경하는 **2단계 검증** 프로세스를 권장합니다.

### ✅ 경쟁사 벤치마킹 및 복제 (`copy_product_test.py`)
- 사용자가 직접 검색한 남자 양말 등 트렌드 상품 페이지를 분석하여, 본인 스토어에 즉시 '판매중지' 상태로 초안을 생성하고 DB에 동기화할 수 있습니다.

### ✅ 실시간 이슈 대응 (Notifications)
- `.env`에 `WEBHOOK_URL`을 설정하면, 자리에 없어도 스마트폰으로 **신규 주문/고객 문의** 알림을 즉시 받아 고객 만족도를 높일 수 있습니다.
