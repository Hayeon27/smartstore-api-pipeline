# 🧪 통합 테스트 가이드

이 문서는 프로젝트의 연결성을 확인하고 기본 기능을 테스트하는 방법을 안내합니다.

## 🚀 실행 방법
터미널에서 아래 커맨드를 입력하면 `NaverCommerceClient`를 직접 호출하여 주요 API의 응답을 확인합니다.
```bash
uv run python main.py
```

## 🔍 주요 테스트 항목
1.  **인증 및 토큰 발급**: `.env`의 자격 증명을 사용하여 OAuth2 토큰을 발급받고 갱신하는 과정을 테스트합니다.
2.  **계정 정보 조회**: 현재 가입된 판매자 계정의 ID와 기본 설정을 가져옵니다.
3.  **브랜드 검색**: 네이버 쇼핑에 등록된 브랜드 정보를 검색하여 클라이언트의 비동기 통신을 검증합니다.
4.  **상품 검색**: 특정 키워드나 조건으로 상품 목록을 가져오는 v1 Search API를 테스트합니다.

## 💡 팁
- 실행 시 로그 레벨을 `DEBUG`로 설정하면 실제 HTTP 요청/응답 헤더와 바디를 모두 확인할 수 있습니다.
- 네트워크 연결이 불안정할 경우 `tenacity`에 의해 자동 재시도가 수행됩니다.
